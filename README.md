# Forge Fitness Studio, AI Gym Website (Demo / Concept)

A complete demo website for a fictional gym in Dewas, Madhya Pradesh, built to show what a small-business AI website package looks like: homepage, classes, pricing, trainers, booking, FAQ, and a rule-based chatbot.

Live demo: https://vedansh2821.github.io/gym-ai-website/

## What it shows

- Hero with class timings and a trial booking call to action
- 7 classes with days, times, coach, intensity, and spots left
- 3 membership plans with a monthly/annual price toggle
- 4 trainer profiles
- Booking enquiry form with validation and a client-side confirmation reference
- FAQ accordion
- Rule-based demo chatbot that answers from the site's own data (prices, timings, trial, trainers, location). No AI API, no API key.

## Tech

Plain HTML, CSS, and JavaScript. No build step, no backend, no paid services. Open `index.html` or serve the folder with any static host.
